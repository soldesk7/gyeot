# 응급실 지도 카카오맵 마커가 검은 네모로 표시됨
- 발생일: 2026-07-23 (SP1)
- 관련 기능: F-05 (응급실 지도)
- 작성자: 최민영(F1)
- 소요: 약 1시간 (원인 후보 배제 반복)

## 증상
`/map` 화면에서 지도는 정상 표시되나, 현재 위치 마커가 빨간 핀 대신 검은 네모로 보임. 본인 PC·팀장 PC·모바일(안드로이드) 모두 동일하게 재현됨.

## 원인
`GuidePage.css`(F2 담당, 화면 C)의 아래 규칙이 원인이었다.

```css
video, img {
  background: #000;
  ...
}
```

.guide-... 클래스로 범위를 좁히지 않고 img 태그 자체를 선택자로 써서, 이 CSS가 앱 전체의 모든 <img>에 전역 적용됐다. 
SPA 특성상 GuidePage.css가 한 번이라도 로드되면 다른 화면(/map)에서도 계속 적용되며, 카카오맵 마커 이미지(투명 배경 PNG)에도 검은 배경이 깔려 마커가 새까맣게 보였다.

## 진단 과정
 - Network 탭: 마커 이미지 요청 200, DevTools Preview에서도 원본 이미지는 정상 → 리소스 로딩 문제 아님을 확인.
 - 여러 브라우저(Edge/Chrome)·기기(PC/폰)에서 동일 증상 → 하드웨어 가속·다크모드 등 기기별 원인 배제.
 - 프로젝트 전체에서 background 관련 CSS 검색 → GuidePage.css의 전역 img 선택자 발견.

## 해결
 - img 선택자를 화면(가이드) 전용 클래스로 좁혀서 다른 화면에 영향 없게 수정 (F2 담당 파일이라 이슈로 전달 후 반영).
 - img, video같은 기본 클래스명이 아니라 guideimg, guidevideo같은 전용클래스를 만들어서 해결

## 재발 방지
 - CSS 선택자는 태그 단독(img, div 등) 대신 화면 전용 클래스로 범위를 좁힌다 — SPA에서는 한 화면의 CSS가 앱 전체에 새어나갈 수 있음.
 - PR 셀프 체크리스트에 "전역 태그 선택자 사용 여부" 항목 추가 검토.
